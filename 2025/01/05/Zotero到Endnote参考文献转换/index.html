EndNote 使用背景

.csl 是zotero使用的参考文献格式，.ens 是Endnote的私有格式

有时我们遇到投稿网站要求指定的参考文献格式，它通常会给出.csl/.ens文件;将其导入文献管理工具就可以轻松使用

但是csl和 ens 格式不能相互转换，如果恰巧使用的是zotero但只有.ens文件；那么就需要重做csl文件或者将zotero文献导入endnote了。

CSL 与 ENS 格式转换的限制

在zotero的讨论栏也有类似的需求，但有回复说二者不能相互转换：https://forums.zotero.org/discussion/81713/endnote-to-csl-migration

Zotero早期可以识别ens的格式文件（Endnote的私有格式）并将其转化为csl（开源协议的格式文件），但是被endnote母公司起诉，所以开发者最终没有保留这个功能（这也是forums评论提到的But there was a (frivolous in my view) lawsuit over that, so zotero devs removed it.）

于是直接转换的方式行不通，只能用别的方式了

方案一：制作或修改 CSL 文件

https://www.zotero.org/support/dev/citation_styles/style_editing_step-by-step

visual citation style language editor 目前官网打不开，主要是编辑非常繁琐：https://blog.csdn.net/m0_51706097/article/details/141461391

所以最终选择了方案2

方案二：从 Zotero 迁移到 EndNote

从 Zotero 导出

ctrl+A 全选或选择需要的文献

在zotero左上角栏选择 文件-导出PDFs

将文件整理到文件夹下，每个文件夹下是pdf文章文件

导入 EndNote 文献库

  1. 首先新建分组集合

新建分组集合：右键点击 MY GROUP - Creat Group Set ；Group Set下方可以有许多小的分组

新建好的集合

  1. 文件归档，先将文件添加到 Imported References（File-Import-Folder）
  1. 再将 Imported References内的文件添加到集合, 选中 Imported References 内的文献，右键添加到对应的集合

批量导入 RIS 文件

EndNote批量导入ris文件方法-CSDN博客

在包含有多个ris文件的文件夹下，新建txt文档，输入下方文字，并另存为bat文件；bat文件和ris文件放在一起

使用 ENS 文件设置 EndNote 引用格式

如果直接有对应的格式，就不用这一步

首先获取到所需参考文献格式的ens文件, 将其另存为endnote文件路径 Style文件夹下

打开word-Endnote栏-Style-Select another stytle, 在弹出的提示框中选择所需的参考文件样式

插入参考文献

光标定位到文字后，word-EndNote20 -Go to EndNote， 在 EndNote里点击所需文献，再回到Word-Insert Citation - Insert Selected Citation
